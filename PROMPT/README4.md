# 🎓 Useful ChatGPT Prompts for Students

รวมตัวอย่าง Prompt ที่ช่วยให้นักศึกษาใช้ ChatGPT เป็นเครื่องมือช่วยในการเรียนและการพัฒนาตนเองได้อย่างมีประสิทธิภาพ ✅

---

## 📚 การเรียนรู้และสรุปเนื้อหา

```

ช่วยสรุปเนื้อหาวิชานี้ \[ใส่ชื่อวิชา] ให้เข้าใจง่ายใน 5 ข้อ

```
```

ช่วยอธิบายหัวข้อนี้ \[ใส่หัวข้อ] ให้เหมือนอธิบายให้เพื่อนที่ไม่เคยเรียนฟัง

```
```

ช่วยยกตัวอย่างโจทย์และวิธีคิดในหัวข้อ \[ใส่หัวข้อ] ให้ฉันลองฝึกทำ

```
```

ช่วยอธิบาย \[ใส่คำศัพท์เฉพาะ] ด้วยภาษาง่าย ๆ พร้อมตัวอย่างประกอบ

```

---

## 📝 การเตรียมตัวสอบ

```

ช่วยสร้างข้อสอบปรนัย 5 ข้อในหัวข้อ \[ใส่หัวข้อ] พร้อมเฉลย

```
```

ช่วยทำ flashcards เพื่อทบทวนวิชานี้ \[ใส่ชื่อวิชา] ในรูปแบบ คำถาม-คำตอบ

```
```

ช่วยสรุป mind map หัวข้อ \[ใส่หัวข้อ] ให้ฉันเอาไปวาดต่อได้

```

---

## 🧠 การวางแผนและจัดการเวลา

```

ช่วยวางแผนการอ่านหนังสือสำหรับ 7 วันก่อนสอบในวิชา \[ใส่ชื่อวิชา]

```
```

ช่วยสร้างตารางเวลาเรียนและพักผ่อนใน 1 วัน ให้สมดุลและมีเวลาพักเพียงพอ

```
```

ช่วยแนะนำเทคนิคการจัดลำดับความสำคัญของงานเมื่อต้องทำหลายอย่างพร้อมกัน

```

---

## ✍️ การเขียนรายงานและเรียงความ

```

ช่วยร่างโครงสร้างรายงานหัวข้อ \[ใส่หัวข้อ] พร้อมหัวข้อย่อย 3-5 ข้อ

```
```

ช่วยแนะนำคำขึ้นต้นและคำลงท้ายที่เหมาะสมสำหรับรายงานทางวิชาการ

```
```

ช่วยตรวจคำผิดและปรับสำนวนในรายงานนี้: \[ใส่ข้อความที่ต้องการตรวจ]

```

---

## 🎤 การเตรียมพรีเซนต์

```

ช่วยเขียนสคริปต์พรีเซนต์ 2-3 นาที หัวข้อ \[ใส่หัวข้อ] พร้อมสรุปใจความสำคัญ

```
```

ช่วยสรุป bullet points สำคัญสำหรับใช้ทำสไลด์หัวข้อ \[ใส่หัวข้อ]

```
```

ช่วยแนะนำเทคนิคการพรีเซนต์ให้ไม่น่าเบื่อและทำให้คนสนใจ

```

---

## 🚀 การพัฒนาตัวเอง

```

ช่วยแนะนำเทคนิคการเรียนรู้ที่เหมาะกับคนที่สมาธิสั้น

```
```

ช่วยสร้าง daily affirmations สำหรับนักศึกษาที่ต้องการเพิ่มความมั่นใจ

```
```

ช่วยแนะนำหนังสือ 3 เล่มที่พัฒนาทักษะการคิดเชิงวิเคราะห์

```
```

ช่วยวางแผนการฝึกภาษาอังกฤษแบบ 30 วันให้ฉัน

```

---

## 🛠 เทคนิคการเขียน Prompt ให้ได้ผลดี
- ระบุ **รายละเอียดวิชา/หัวข้อให้ชัดเจน**
- ใช้คำกริยาเช่น "ช่วยสรุป", "ช่วยสร้าง", "ช่วยตรวจสอบ"
- ให้ข้อมูลประกอบ เช่น "จำนวนวันก่อนสอบ", "รูปแบบข้อสอบ"
- ระบุระดับความลึก เช่น "ให้เข้าใจใน 5 ข้อ", "แบบภาษาง่าย ๆ"

---

## ✅ วิธีใช้งาน
1. คัดลอก Prompt ไปใช้ใน ChatGPT ได้ทันที
2. แก้ไข [ข้อความในวงเล็บ] ให้ตรงกับวิชาหรือหัวข้อที่เรียน
3. ลองปรับโจทย์ให้เข้ากับสไตล์การเรียนของคุณเอง
