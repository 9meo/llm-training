# 🎯 Zero-shot vs Few-shot Prompting Example

ตัวอย่างนี้จะแสดงความแตกต่างระหว่าง **Zero-shot Prompting** และ **Few-shot Prompting** โดยเน้นให้เห็น **ผลลัพธ์ที่แตกต่างกันอย่างชัดเจน**

---

## 📌 Zero-shot Prompting คืออะไร?

- การให้โจทย์กับ LLM โดย **ไม่ให้ตัวอย่างใด ๆ เลย**
- ตัว LLM ต้องเข้าใจและตอบตามคำสั่งโดยอิงจากความรู้ที่มี

---

## 📌 Few-shot Prompting คืออะไร?

- การให้โจทย์กับ LLM พร้อม **ตัวอย่าง 1-5 ตัวอย่างใน Prompt**
- ช่วยให้ LLM เข้าใจรูปแบบที่เราต้องการได้ชัดเจนขึ้น
- ส่งผลให้คำตอบตรงกับที่เราคาดหวังมากขึ้น

---

# 🔍 ตัวอย่างเปรียบเทียบ

## 🎯 Task: แปลงข้อความเป็นประโยคเชิงบวก (Positive Rephrasing)

---

### 🟥 Zero-shot Example

**Prompt:**
```

เปลี่ยนข้อความนี้ให้อยู่ในรูปแบบเชิงบวก: "ฉันล้มเหลวในการทำโปรเจค"

```

**ผลลัพธ์:**
```

ฉันล้มเหลวในการทำโปรเจค แต่ฉันจะพยายามใหม่ในครั้งต่อไป

```

🔍 **ข้อสังเกต:**
- โมเดลพยายามเปลี่ยนปลายประโยค แต่ยังคงใช้คำว่า "ล้มเหลว" ซึ่งไม่เชิงบวก 100%
- ไม่มีตัวอย่างทำให้โมเดลไม่เข้าใจรูปแบบที่ต้องการเป๊ะ ๆ

---

### 🟩 Few-shot Example

**Prompt:**
```

ตัวอย่าง:

* Input: ฉันทำงานพลาด

* Output: ฉันได้เรียนรู้จากความผิดพลาดและจะทำได้ดีขึ้นในอนาคต

* Input: วันนี้อากาศร้อนเกินไป

* Output: วันนี้เป็นโอกาสดีที่จะได้ดื่มน้ำเย็นสดชื่น

* Input: ฉันล้มเหลวในการทำโปรเจค

* Output:

```

**ผลลัพธ์:**
```

ฉันได้โอกาสเรียนรู้จากโปรเจคนี้ และจะพัฒนาให้ดียิ่งขึ้นในครั้งหน้า

```

🔍 **ข้อสังเกต:**
- โมเดลเข้าใจรูปแบบการเปลี่ยนเป็นเชิงบวกที่เราต้องการชัดเจน
- โครงสร้างประโยคสอดคล้องกับตัวอย่าง
- ได้คำตอบที่เป็นบวกและสร้างแรงบันดาลใจมากกว่า Zero-shot

---

# ✅ สรุปความแตกต่าง

| Feature                | Zero-shot                     | Few-shot                                 |
|-----------------------|------------------------------|------------------------------------------|
| ตัวอย่างใน Prompt    | ไม่มี                          | มี 1-5 ตัวอย่าง                         |
| ความแม่นยำ           | ปานกลาง                      | สูง                                       |
| โทนที่ได้            | อาจไม่ตรงตามที่ต้องการ         | ตรงโทนและโครงสร้างที่เรากำหนด           |
| ความเข้าใจบริบท      | ต้องพึ่งความรู้โมเดลเป็นหลัก   | โมเดลเรียนรู้จากตัวอย่างที่เราให้        |

---

## 🛠 วิธีใช้งาน
1. คัดลอก Prompt ที่ต้องการไปใช้งานใน ChatGPT
2. ทดลองเปลี่ยนโจทย์ เพื่อเปรียบเทียบผลลัพธ์ด้วยตัวเอง
3. ลองเพิ่มจำนวนตัวอย่างใน Few-shot เพื่อดูผลลัพธ์ที่ละเอียดขึ้น

---

> เอกสารนี้จัดทำขึ้นเพื่ออธิบายการใช้งาน Prompt แบบ Zero-shot และ Few-shot พร้อมผลลัพธ์ที่จับต้องได้ 💬
