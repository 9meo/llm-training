# 🎯 10 Prompts for Daily Life

รวม 10 ตัวอย่าง Prompt ที่ช่วยให้ชีวิตประจำวันของคุณง่ายขึ้น ลองนำไปใช้กันเลย!

---

## 💡 1. Meal Planning – วางแผนมื้ออาหาร
```

สร้างแผนมื้ออาหาร 1 สัปดาห์ที่มีทั้งโปรตีนและผัก ใช้เวลาทำไม่เกิน 30 นาที พร้อมวิธีทำคร่าวๆ

```

---

## 🧘‍♀️ 2. Manage Stress & Motivation – จัดการความเครียดและสร้างแรงบันดาลใจ
```

แนะนำกลยุทธ์ที่จะช่วยให้ผมมีแรงจูงใจในการทำงานและมีสมาธิจดจ่อมากขึ้น

```

---

## ✈️ 3. Travel Planning – วางแผนท่องเที่ยว
```

สมมติว่าคุณเป็นไกด์ท่องเที่ยว ช่วยแนะนำสถานที่ท่องเที่ยวและเวลาที่ดีที่สุดในการเที่ยว \[ชื่อสถานที่] หน่อยครับ

```

---

## 🏋️ 4. Health & Exercise – สุขภาพและการออกกำลังกาย
```

ช่วยอธิบายท่าสเตรชและการออกกำลังกายที่ช่วยบรรเทาอาการปวดหลัง โดยละเอียดหน่อยครับ

```

---

## 💼 5. Career Advice – คำแนะนำด้านอาชีพ
```

ช่วยหาข้อมูลเกี่ยวกับอุตสาหกรรม \[ชื่ออุตสาหกรรม] ที่ผมจะนำไปใช้เขียน Cover Letter

```

---

## 🧠 6. Anxiety Management – การจัดการความวิตกกังวล
```

แนะนำวิธีฝึกสติที่ช่วยลดความวิตกกังวลและทำให้จดจ่อกับปัจจุบันมากขึ้น

```

---

## 💰 7. Budget Planning – วางแผนการเงิน
```

ช่วยสร้างแผนงบประมาณสำหรับการใช้ชีวิต 3 เดือนในประเทศไทย รวมค่าอาหาร ที่พัก และงบสำหรับท่องเที่ยว

```

---

## 📚 8. Education & Learning – การศึกษาและการเรียนรู้
```

ช่วยสรุปบทความนี้ \[ลิงก์] เป็น 3–5 ข้อสำคัญ และเขียนสรุปสั้นๆ สำหรับกลุ่มเรียน

```

---

## 📱 9. Social Media & Content Creation – โซเชียลมีเดียและการสร้างคอนเทนต์
```

ช่วยออกแบบแคมเปญโซเชียลมีเดียสำหรับร้านอาหารกรีกที่กำลังจะเปิดใหม่ รวมถึงความถี่ในการโพสต์และไอเดียคอนเทนต์

```

---

## 👪 10. Family Activities – กิจกรรมครอบครัว
```

แนะนำ 10 ไอเดียเดทกับแฟน ทั้งในบ้าน กลางแจ้ง และในรัศมี 10 กิโลเมตร

```

---
