## ⏰ การจัดการเวลาและงาน

### 📅 จัดตารางเวลา
```
คุณเป็นโค้ชด้านการจัดการเวลา นี่คือตารางเวลารายสัปดาห์ของฉัน: [ระบุตาราง] 
ช่วยปรับปรุงโดยใช้การแบ่งช่วงเวลาทำงาน พัก และจัดกลุ่มงาน อธิบายเหตุผลด้วย
```

### 🎯 ตั้งเป้าหมาย
```
ช่วยฉันกำหนดเป้าหมาย 3 อันดับแรกสำหรับสัปดาห์นี้ 
ถามคำถามสั้นๆ เพื่อช่วยฉันตัดสินใจ แล้วสร้างแผนที่มีเป้าหมาย ระยะเวลา และงานที่ชัดเจน
```

## 💪 สุขภาพและสุขภาพจิต

### 😴 ปรับปรุงการนอน
```
นี่คือกิจวัตรการนอนของฉัน: [อธิบาย] 
แนะนำแผนการผ่อนคลายก่อนนอนที่ดีขึ้น และอธิบายว่าช่วยให้หลับลึกและพักผ่อนดีอย่างไร
```

### 🏃‍♂️ ออกกำลังกาย
```
คุณเป็นเทรนเนอร์ส่วนตัว ออกแบบโปรแกรมออกกำลังกายสำหรับผู้เริ่มต้นที่มีเวลา 30 นาทีต่อวัน 
เป้าหมายคือ [เช่น ลดน้ำหนัก, เพิ่มกล้ามเนื้อ]
```

## 🎨 ความคิดสร้างสรรค์

### 💡 สร้างไอเดีย
```
คุณเป็นผู้ช่วยระดมความคิด สร้าง 10 ไอเดียที่ไม่ซ้ำใครสำหรับ [ระบุหัวข้อหรือโปรเจกต์] 
โดยเน้นแนวทางที่สร้างสรรค์และนอกกรอบ
```

### 📖 เขียนเรื่องสั้น
```
เขียนเรื่องสั้นเกี่ยวกับ [ระบุธีมหรือสถานการณ์] สำหรับเด็กอายุ 5-8 ปี ความยาว 200 คำ
```

---

## 📚 การเรียนรู้และการศึกษา

### 📋 แผนการเรียน
```
คุณเป็นโค้ชการเรียนรู้ ฉันต้องการเรียน [ระบุทักษะ] ใน 30 วัน 
สร้างแผนการเรียนรู้สำหรับผู้เริ่มต้น รวมถึงงานประจำวัน ทรัพยากร และเป้าหมาย
```

### 🧠 อธิบายง่ายๆ
```
อธิบาย [หัวข้อที่ซับซ้อน] ด้วยภาษาง่ายๆ 
โดยใช้การเปรียบเทียบและตัวอย่างที่ทุกคนเข้าใจได้
```

---

## 💬 การสื่อสาร

### 📧 เขียนอีเมล
```
คุณเป็นนักเขียนมืออาชีพ เขียนอีเมลที่ชัดเจนและน่าสนใจสำหรับ [ระบุวัตถุประสงค์ เช่น สมัครงาน] 
โดยกำหนดเป้าหมายไปที่ [ระบุกลุ่มเป้าหมาย]
```

### 🎤 เตรียมสัมภาษณ์
```
คุณเป็นโค้ชด้านการสัมภาษณ์ เตรียมฉันสำหรับการสัมภาษณ์งานในตำแหน่ง [ระบุตำแหน่ง] 
โดยสร้างคำถามที่เป็นไปได้และคำตอบตัวอย่างตามมาตรฐานอุตสาหกรรม
```

## 🏠 การจัดการชีวิตประจำวัน

### ✈️ วางแผนทริป
```
วางแผนทริป 7 วันใน [ระบุสถานที่] รวมร้านอาหารราคาประหยัด สถานที่ท่องเที่ยว และวันพักผ่อน 
งบประมาณ [ระบุจำนวน] ต่อวัน
```

### 💰 จัดการงบประมาณ
```
นี่คือรายรับและรายจ่ายของฉัน: [ระบุรายละเอียด] 
วิเคราะห์และแนะนำ 3 วิธีลดค่าใช้จ่ายโดยไม่ลดคุณภาพชีวิต
```

## 💡 เทคนิคการใช้งาน

### ✅ วิธีใช้ให้มีประสิทธิภาพ
1. **แทนที่ข้อความในวงเล็บ [ ]** ด้วยข้อมูลจริงของคุณ
2. **เพิ่มรายละเอียดเฉพาะ** ยิ่งละเอียดมากยิ่งได้คำตอบที่ดี
3. **ขอให้แก้ไขหรือเพิ่มเติม** หาก AI ตอบไม่ตรงตามต้องการ
4. **บันทึกผลลัพธ์ที่ได้** เพื่อนำไปใช้ประโยชน์ต่อไป

### 🎯 ตัวอย่างการปรับแต่ง
- **เพิ่มบริบท**: "สำหรับคนที่ทำงานแบบ WFH"
- **กำหนดรูปแบบ**: "จัดเป็นตารางที่อ่านง่าย"
- **ระบุข้อจำกัด**: "ใช้เวลาไม่เกิน 1 ชั่วโมงต่อวัน"
