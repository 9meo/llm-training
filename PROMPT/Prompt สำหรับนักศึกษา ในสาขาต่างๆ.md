## 🔬 วิทยาศาสตร์และวิศวกรรมศาสตร์

### 🎯 เทคนิคที่แนะนำ
- **ขอเหตุผลแบบขั้นตอน** - ให้ AI แสดงขั้นตอนการคิดอย่างละเอียด
- **ขอตัวอย่างประกอบ** - ขอตัวอย่างเพื่อความเข้าใจที่ชัดเจน

### 🧪 ตัวอย่าง Prompts

#### เคมี/ชีววิทยา
```
อธิบายกระบวนการสังเคราะห์แสงในพืช รวมถึงสมการเคมีที่เกี่ยข้อง 
แสดงขั้นตอนการเปลี่ยนแปลงทีละขั้น และยกตัวอย่างในชีวิตจริง
```

#### วิศวกรรม/ฟิสิกส์
```
ออกแบบวงจรที่มีตัวต้านทาน คาปาซิเตอร์ และหลอดไฟ LED 
พร้อมอธิบายวิธีการทำงาน คำนวณค่าอุปกรณ์ และวาดไดอะแกรม
```

#### คณิตศาสตร์
```
อธิบายการประยุกต์ใช้แคลคูลัสในการแก้ปัญหาการหาค่าเหมาะสมที่สุด 
ยกตัวอย่างจากปัญหาทางเศรษฐศาสตร์หรือวิศวกรรม พร้อมแสดงขั้นตอนการคำนวณ
```

#### วิทยาการคอมพิวเตอร์
```
อธิบาย Algorithm การเรียงลำดับแบบ Quick Sort 
แสดงขั้นตอนการทำงาน เขียน pseudocode และวิเคราะห์ Big O notation
```

## 📚 มนุษยศาสตร์

### 🎯 เทคนิคที่แนะนำ
- **ใช้บริบทประวัติศาสตร์** - เชื่อมโยงกับยุคสมัยและสถานการณ์
- **วิเคราะห์เชิงลึก** - ขุดลึกความหมายและสัญลักษณ์

### 📖 ตัวอย่าง Prompts

#### วรรณกรรม
```
วิเคราะห์สัญลักษณ์ใน 'แมคเบ็ธ' โดยเน้นที่สัญลักษณ์ของเลือด 
อธิบายความหมายในบริบทของเรื่อง การเปลี่ยนแปลงของตัวละคร 
และเชื่อมโยงกับธีมหลักของเรื่อง
```

#### ประวัติศาสตร์
```
อภิปรายผลกระทบของการปฏิวัติอุตสาหกรรมต่อโครงสร้างสังคมในยุโรปศตวรรษที่ 19
วิเคราะห์การเปลี่ยนแปลงทางเศรษฐกิจ สังคม และวัฒนธรรม พร้อมยกตัวอย่างเฉพาะเจาะจง
```

#### ปรัชญา
```
เปรียบเทียบแนวคิดเรื่องความยุติธรรมของอริสโตเติลและจอห์น รอว์ลส์ 
วิเคราะห์ความแตกต่างและความเชื่อมโยง พร้อมประยุกต์ใช้กับปัญหาร่วมสมัย
```

#### ภาษาศาสตร์
```
อธิบายการเปลี่ยนแปลงของภาษาไทยจากสุโขทัยถึงปัจจุบัน 
โดยเน้นการเปลี่ยนแปลงของระบบเสียง ไวยากรณ์ และคำศัพท์
```

## 🌍 สังคมศาสตร์

### 🎯 เทคนิคที่แนะนำ
- **เปรียบเทียบทฤษฎี** - นำทฤษฎีต่างๆ มาเปรียบเทียบ
- **ขอตัวอย่างจากกรณีศึกษา** - ใช้ตัวอย่างจริงประกอบ

### 🏛️ ตัวอย่าง Prompts

#### รัฐศาสตร์
```
เปรียบเทียบทฤษฎีของคาร์ล มาร์กซ์และแมกซ์ เวเบอร์เกี่ยวกับระบบทุนนิยม 
วิเคราะห์จุดเด่น จุดอ่อน และความเกี่ยวข้องกับสังคมปัจจุบัน
```

#### มานุษยวิทยา
```
อธิบายแนวคิดความสัมพันธ์ทางวัฒนธรรม (Cultural Relativism) 
พร้อมยกตัวอย่างจากวัฒนธรรมต่างๆ และอภิปรายข้อดีข้อเสีย
```

#### จิตวิทยา
```
วิเคราะห์ทฤษฎีการพัฒนาการทางจิตใจของเอริก เอริกสัน 
อธิบายแต่ละขั้นตอน พร้อมยกตัวอย่างพฤติกรรมในแต่ละวัย
```

#### สังคมวิทยา
```
อธิบายแนวคิด "การทำให้เป็นสินค้า" (Commodification) ในสังคมทุนนิยม
ยกตัวอย่างจากสื่อสังคมออนไลน์ การศึกษา หรือการดูแลสุขภาพ
```

## 🎨 ศิลปะและความคิดสร้างสรรค์

### 🎯 เทคนิคที่แนะนำ
- **ใช้การแสดงบทบาท** - ให้ AI รับบทบาทเป็นศิลปิน/นักเขียน
- **สร้างงานสร้างสรรค์** - ขอให้สร้างผลงานต้นฉบับ

### 🎭 ตัวอย่าง Prompts

#### วรรณกรรมสร้างสรรค์
```
เขียนเรื่องสั้นในสไตล์ของเอดการ์ อัลลัน โป โดยรวมถึงธีมความลึกลับ 
ใช้เทคนิคการเล่าที่สร้างความตึงเครียดและบรรยากาศที่น่าสะพรึงกลัว
```

#### บทกวี
```
สร้างบทกวีบรรยายถึงบรรยากาศของวันฝนตกในเมืองที่วุ่นวาย 
ใช้ภาพพจน์ที่เปรียบเทียบธรรมชาติกับชีวิตคนเมือง
```

#### ศิลปะทัศนศิลป์
```
วิเคราะห์การใช้สีและแสงในภาพเขียนของโคลด โมเนต์ 
อธิบายเทคนิคอิมเพรสชันนิสม์และอิทธิพลต่อศิลปะสมัยใหม่
```

#### ดนตรี
```
อธิบายโครงสร้างของ Sonata Form ในดนตรีคลาสสิก 
ยกตัวอย่างจากผลงานของโมสาร์ทหรือเบโทเฟน พร้อมวิเคราะห์องค์ประกอบ
```

## 💼 ธุรกิจและเศรษฐศาสตร์

### 🎯 เทคนิคที่แนะนำ
- **วิเคราะห์ข้อมูล** - ขอให้วิเคราะห์ตัวเลขและแนวโน้ม
- **พัฒนากลยุทธ์** - สร้างแผนที่ใช้งานได้จริง

### 📊 ตัวอย่าง Prompts

#### เศรษฐศาสตร์
```
วิเคราะห์ปัจจัยที่นำไปสู่วิกฤตการณ์ทางการเงินในปี 2008 และผลกระทบระยะยาว 
อธิบายกลไกการแพร่กระจายวิกฤตและมาตรการแก้ไขที่ใช้
```

#### การตลาด
```
พัฒนากลยุทธ์การตลาดสำหรับผลิตภัณฑ์ที่เป็นมิตรกับสิ่งแวดล้อม 
โดยเน้นกลุ่มวัยมิลเลนเนียล รวมถึงช่องทางการสื่อสารและการวัดผล
```

#### การจัดการ
```
วิเคราะห์ทฤษฎีภาวะผู้นำของจอห์น แม็กซ์เวลล์ 
ประยุกต์ใช้ในการบริหารทีมงานยุค Remote Work พร้อมตัวอย่างเครื่องมือ
```

#### การเงิน
```
อธิบายแนวคิด Portfolio Theory ของมาร์โควิทซ์ 
รวมถึงการคำนวณความเสี่ยงและผลตอบแทนที่คาดหวัง พร้อมตัวอย่างการใช้งาน
```

## 💡 เทคนิคการใช้งาน

### ✅ หลักการเขียน Prompt ที่ดี

#### 🎯 ความชัดเจน
- **ระบุเป้าหมาย**: บอกว่าต้องการอะไรอย่างชัดเจน
- **กำหนดขอบเขต**: ระบุความยาว รูปแบบ หรือจุดเน้น
- **ให้บริบท**: เพิ่มข้อมูลเบื้องหลังที่เกี่ยวข้อง

#### 📝 โครงสร้าง
```
[บทบาทของ AI] + [งานที่ต้องการ] + [รูปแบบผลลัพธ์] + [ข้อกำหนดเพิ่มเติม]
```

**ตัวอย่าง:**
```
คุณเป็นอาจารย์ประวัติศาสตร์ [บทบาท] 
อธิบายสาเหตุของสงครามโลกครั้งที่ 1 [งาน] 
ในรูปแบบเรียงความ 500 คำ [รูปแบบ] 
โดยเน้นปัจจัยทางเศรษฐกิจและการเมือง [ข้อกำหนด]
```

### 🔧 เทคนิคขั้นสูง

#### 🧠 Chain of Thought
```
อธิบายขั้นตอนการคิดของคุณทีละขั้น เริ่มจาก... จากนั้น... สุดท้าย...
```

#### 🎭 Role Playing
```
คุณเป็น [บทบาท] ที่มีประสบการณ์ [X] ปี ในสาขา [Y]
```

#### 📊 Few-Shot Learning
```
ตัวอย่างที่ 1: [ตัวอย่าง]
ตัวอย่างที่ 2: [ตัวอย่าง]
ตอนนี้ทำแบบเดียวกันกับ: [งานจริง]
```

### ⚠️ ข้อควรระวัง

#### ❌ สิ่งที่ควรหลีกเลี่ยง
- คำถามที่คลุมเครือเกินไป
- ขอข้อมูลที่ล้าสมัยหรือเป็นความลับ
- ใช้ภาษาที่ซับซ้อนโดยไม่จำเป็น

#### ✅ สิ่งที่ควรทำ
- ขอให้ตรวจสอบคำตอบอีกครั้ง
- ขอแหล่งอ้างอิงเพิ่มเติม
- ปรับแต่ง prompt หากผลลัพธ์ไม่ตรงต้องการ
